# E-Commerce Sales & Customer Analysis | MySQL

## Project Overview
This project analyzes e-commerce sales and customer purchasing behavior using MySQL.

## Database Tables
- Customers
- Orders
- Order Items
- Products

## Key Analysis
- Calculated revenue and freight charges from delivered orders.
- Identified top 10 product categories by revenue.
- Analyzed top customers by spending.
- Identified repeat customers and calculated their percentage.
- Analyzed monthly revenue and order trends.
- Ranked product categories using the `RANK()` window function.

## SQL Skills Used
- SELECT, WHERE, GROUP BY, ORDER BY
- JOINs
- Aggregate functions
- Common Table Expressions (CTEs)
- Window functions

## Tools
- MySQL
- MySQL Workbench
